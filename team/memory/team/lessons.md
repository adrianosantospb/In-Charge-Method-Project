# Team lessons

Lessons that apply to every project. Newest first.

## Delivery

- [lesson] Read every file back after writing it and compare it. A write can report success while an older version stays in place. #delivery ([[001]])
- [lesson] State what you could not run in the user's real environment, such as Docker or another browser, and give the commands to check it. #delivery ([[001]])

## Reviews

- [lesson] A review named in the plan is not enough: the feature file's plan table must list it as a step, or it can be skipped without anyone noticing. #process ([[002]], [[tasks]])
- [lesson] Small changes made after a security review tend to go unreviewed. Review them again or record that they were not reviewed. #security ([[001]])
